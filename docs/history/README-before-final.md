# Earlier README summary

The project started with a local MiniWoB agent, then added evaluation and recovery tests.
After the frozen comparison, it gained a benchmark viewer, a Books to Scrape trial,
a Wikipedia search demo and a separate-browser Google Forms app.

The current product is the Chrome extension, which works in the user's existing tab.
Earlier demos remain in the repository, but aren't its main entry point.

This file is now a short summary. Its full earlier text remains in Git history.
See the [current README](../../README.md) and [project notes](../PROJECT-DETAILS.md).
