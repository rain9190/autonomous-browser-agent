# Phase 4: narrow visible benchmark-link spans

The browser audit found span.alink controls without usable AX link/button roles
in click-link, click-collapsible-2, click-tab-2-easy and click-tab-2-medium. This
update adds visible control metadata for exactly those four local task IDs.
It does NOT enable arbitrary generic-node, span or general website clicks.

## User-run verification

    python -m pytest tests -q
    RUN_BROWSER_TESTS=1 python -m pytest tests/test_browser_benchmark_links.py -q

Expected offline suite: 251 passed, ten opt-in browser checks skipped. The second
command runs three Chromium checks without model calls: click the goal-named
visible span, prove collapsed/other-panel links stay hidden as panels change,
and prove a non-link container is rejected by the native mapping guard.

After the three checks pass:

    python -m browser_agent --task click-link --seed 61 --max-steps 2

Expected autonomous behavior: click_benchmark_link on the visible target, full
credit, normally one action/API call. Two is only the maximum allowance. Use
only development seeds; reserved final seeds remain untouched. Failures are
retained, not selectively retried until a good result is obtained.

## Observation supplement

observations.enrich_benchmark_links reads a FIXED DOM metadata query for
#area span.alink on four explicitly allowlisted task specs. It also checks the
current page has a file: URL ending in one of those task names. Only rendered
positive-size elements with visible style and no hidden/aria-hidden ancestor
are exposed. Other panels' hidden links are excluded. This is rendered visibility,
not a promise of viewport intersection or successful click actionability.

Each supplement line is [bid] benchmark_link followed by a Python-quoted label.
benchmark_link is a project-defined control-metadata tag, NOT a native browser
accessibility role. Labels are textContent only, bounded at 256 characters;
IDs follow the existing identifier pattern, duplicates are rejected and at most
40 link records are accepted. Escaped text cannot create extra role lines.
No expected-answer variables, task reward internals or hidden links are queried.
Metadata does not choose the target, change element IDs or mutate the page.
The existing 8,000-character tree/catalogue bounds still apply after enrichment.

Both iterative observation and one-shot initial planning use the same helper.
One-shot's executor refreshes it only for deterministic target validation, never
for a new model decision. The comparison worker hashes the enriched initial
observation in BOTH arms, including through its environment wrapper. Controlled
recovery tasks are outside this supplement scope and retain their previous
post-failure fingerprint path. Changes to observations/prompts must be recorded
by source hashes; prior comparisons remain historical rather than overwritten.

## Action and native guard

click_benchmark_link takes only an observed supplemented ID, with null text and
checked. It has a separate legal-target catalogue entry. Generic AX IDs, hidden
span IDs, buttons and unrelated anchors do not become eligible for this action.
The mapping again checks the local task page, exact span.alink selector and
visibility before its fixed Playwright click. No force-click, arbitrary selector,
arbitrary JS generated by the model or navigation permission is added. The fixed
read/guard JavaScript is a benchmark-specific adapter justified by missing AX
semantics, not a model-executable JavaScript tool.

Tab activation and other action validators remain unchanged. Link errors stop;
recovery is still eligible fill-only. Budget limits, full-credit metric and API
configuration are unchanged. The model is told that hidden links require opening
an observed panel, not guessing a hidden ID. No hidden-target IDs are provided
to the one-shot planner; its fixed plan still cannot replan after revealing a UI.

## Provisional task exposure and limits

The four task IDs are now development-runnable in the CLIs/evaluator. Their
protocol manifest remains candidate until development episodes are inspected.
This does not mark the complete 20-task protocol frozen or supported. Generic
span/real-link support outside these exact local pages is deliberately absent.
The pending seven-action budget for ordinary checkboxes is a separate change.
